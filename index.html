          Math & Methodology
          
Transparent Health Scoring Method

        

        
      


      

        Codebase Doctor avoids invented or arbitrary numerical scores. The health score is calculated transparently from verified findings:
      


      

        Score = Math.max(0, Math.min(100, Math.round(100 - Penalty / Normalizer)))
      


      

        Calculating current project score breakdown...
      


      
    
        
  • Critical Severity: -15 penalty points (security flaws, syntax breaks, eval).
    • 
        
  • High Severity: -8 penalty points (mutable defaults, bare except, broken imports).
    • 
        
  • Medium Severity: -3 penalty points (duplicate blocks, high complexity >8, excessive nesting ≥5).
    • 
        
  • Low Severity: -1 penalty point (missing docstrings, leftover debug logs).
    • 
        
  • Normalizer: Math.max(1, TotalFiles * 0.4) scales deductions fairly for larger repositories.

        Notice on Clean Scores: A score of 100/100 indicates zero violations detected across all active 28 static analysis rules. It does not imply code is mathematically proven bug-free.
